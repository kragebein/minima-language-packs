# Minima language packs

Public download host for signed Minima prediction data. The application source is maintained separately.

## Norwegian

Norwegian is the first pack and includes English vocabulary commonly used alongside Norwegian.
Download and update it from **Minima → Keyboard settings → Languages**.

Stable signed catalog:

https://github.com/kragebein/minima-language-packs/releases/latest/download/catalog.json

Each `nb-rN` release contains the complete data, keyboard layout, manifest, file checksums and attribution. Revisions are published only after all assets have uploaded. Updates preserve the signing identity trusted by the app.

## Data credits

Every pack includes `PREDICTION-CREDITS.txt`, `ATTRIBUTION.txt` and `language-data.md`. These describe the individual data sources and their licenses, including the Norsk ordbank and wordfreq-derived vocabulary. Retain these files when redistributing the data; this repository does not replace their terms with a different license.
